# Contributing to Open Stage Island

Thank you for contributing to the Open Stage Island documentation hub!

## How to contribute

### Reporting bugs
Use the **Bug report** issue template. Include:
- Your Second Life viewer version
- The region and coordinates where the bug occurred
- Steps to reproduce
- Expected vs. actual behavior

### Proposing features
Use the **Feature request** issue template. We welcome ideas for:
- New events or DJ nights
- Venue improvements
- Technical fixes
- Community initiatives

### Editing content
This is a Jekyll GitHub Pages site. To update content:

1. Fork this repository
2. Edit the relevant `.md` file in the root directory
3. Submit a pull request

For large changes, open an issue first to discuss the approach.

## Getting help

- **Second Life technical support:** [community.secondlife.com](https://community.secondlife.com/)
- **Security issues:** See the `SECURITY.md` link in the issue template config
- **General questions:** Open a Discussion

## Code of conduct

All contributors are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
This project is LGBTQI+ friendly and furry-friendly. Be respectful to all visitors.
