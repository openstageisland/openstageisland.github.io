# The vanity-domain detail, because it is the one that bites here: this site is
# served at openstageis.land via CNAME, while the repository openstageisland
# also builds and serves it at openstageisland.github.io. Canonicals and og:url
# are always built from `origin:` in _data/seo.yml, which is the CNAME host, and
# never from the host a page happened to be requested on. The repository host is
# declared as an alias in website.aliases so a crawler landing there is pointed
# at the canonical rather than left to guess. scripts/check_seo.py fails the
# build if origin and CNAME ever disagree -- which is the single check that keeps
# this site from being de-indexed on its real domain.

# are all meant to be found.
