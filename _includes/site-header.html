{%- comment -%} site-header.html — top bar for the single-page visitor guide. Class structure mirrors the sibling Jekyll sites (neohiro.github.io, transhumanists.github.io): .site-header > .container > .site-brand + .site-nav > .nav-link Two deliberate differences from those sites: 1. It is NOT sticky. assets/css/site-chrome.css pins it to `position: static` so it scrolls away with the document; the persistent bottom bar is the only always-on chrome. The siblings pin their header with `position: sticky`, which must not be copied here. 2. There is no static login slot. The shared template's nav.html carries a hand-written `.nav-login-slot`, but assets/js/network-ux.js injectNavAuth() also injects Login / Dashboard / user chips into `.site-nav`. Shipping both would render two Login controls, so this include omits the static slot and lets injectNavAuth() own auth state. injectNavAuth() inserts its chips immediately before `.nav-sponsor`, so the sponsor link has to remain the final child of .site-nav. {%- endcomment -%}
